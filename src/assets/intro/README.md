# Sunset Survivors — assets separados

29 recortes PNG extraídos da folha de assets gerada. As imagens são recortes da arte original, não arquivos-fonte independentes: alguns incluem fundo preto, textos, sombras ou elementos vizinhos. Transparência verdadeira e camadas ocultas não podem ser recuperadas com fidelidade.

Para Phaser 3, use os cenários como camadas de referência, e prefira os spritesheets originais do projeto para personagens animados. Os textos de HUD e botões devem ser dinâmicos.

Os recortes têm resoluções variadas e podem exigir limpeza manual antes de produção.
