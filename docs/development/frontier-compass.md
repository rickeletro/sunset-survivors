# Frontier HUD compass

The compass replaces the bottom-of-screen building direction list. It sits on the right, below gold/kills, as a free-standing translucent brass compass with a north-up face. The player stays centered. Gold dots identify saloons (including Faro in stage 2), red bullseyes identify target practice, and green squares identify hospitality. The rectangular backing and activity legend are removed; only cardinal labels remain. The face uses 65% layer opacity with a faint circular tint; player and activity markers keep their independent opacity for readability. Existing in-world doorway labels, input and interaction rules are preserved.

A 2,000-world-pixel radius maps proportionally to 76 HUD pixels. Nearby doors appear at their relative position; distant available activities become outward bearings on the rim. Only the nearest available distant doorway per activity is retained, preventing several settlement hubs from stacking indistinguishable pins. Used local doors fade; used distant doors do not advertise availability. Faro remains advertised while its existing repeat-visit rule permits another attempt. Doors within entry range receive a subtle pulse. No enemy positions or undiscovered reward information are added.

The rendering uses one static graphics layer, one reusable dynamic graphics layer, live cardinal/legend labels and a separate player glyph. Dynamic geometry updates at most ten times per active second and allocates no new display objects during updates. There is no second camera, minimap render texture, shader or particle emitter. Pause uses the existing scene clock; interiors, upgrade choices and onboarding hide the instrument. Resize positioning and all shutdown listeners are covered by automated tests, along with projection, rim bearings, consumed doors, Faro retries, all eight stages and removal of the footer integration.
